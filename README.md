# Padaria Gustmann | Site Institucional

Site institucional oficial da **Padaria Gustmann (Padaria e Confeitaria)**, desenvolvido em Next.js 14, TypeScript e Tailwind CSS.

16 anos de tradição levando pães fresquinhos todos os dias, qualidade e sabor que fazem a diferença em Americana - SP.

## 🛠️ Como rodar o projeto

1. Clone o repositório:
```bash
git clone https://github.com/Arthur-Santinati/padaria-gustmann.git
cd padaria-gustmann
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

4. Acesse no navegador:
`http://localhost:3000`
